# Portfolio Facundo

Sitio público que presenta el perfil, los proyectos y la experiencia de Facundo Albano. El CV es la fuente de los hechos; el sitio puede ampliarlos, no contradecirlos.

## Language

**Proyecto destacado**:
Un trabajo listado en la sección Proyectos Destacados del CV. Hoy: Sunshine, Sistema de Gestión Clínica, Tu Invitación, TRRO, Alterna.
_Avoid_: Portfolio Personal como si fuera un Proyecto destacado del CV

**Portfolio Personal**:
Este sitio. Se muestra al final como tarjeta mínima, sin video. No es un Proyecto destacado.
_Avoid_: Darle el mismo peso que Sunshine, Clínica o Tu Invitación

**Tu Invitación**:
Plataforma web multi-evento de invitaciones digitales personalizables (cumpleaños de 15): experiencia pública del invitado, admin del operador, RSVP, CSV, temas y link privado para la organizadora. El código es privado; en el sitio solo se muestra el enlace de demo.
_Avoid_: Clínica de invitaciones, “el último proyecto”, Invitaciones web (como nombre propio)

**Experiencia freelance**:
Trabajo como Desarrollador Full Stack Freelance (2024 – actualidad): sistemas reales en producción para clientes.
_Avoid_: “3+ años de experiencia”, experiencia laboral formal en software si no está en el CV

**Experiencia laboral adicional**:
El rol administrativo en la Terminal de Ómnibus de Rosario. Complementa el perfil; no sustituye la Experiencia freelance.
_Avoid_: Presentarla como la experiencia profesional principal
